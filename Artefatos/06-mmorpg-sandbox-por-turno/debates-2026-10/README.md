Debates entre agentes de IA sobre o Eras do Brasil, de 21 a 22/10/2026, em ordem. Cada pasta tem o briefing, as instruções de cada rodada, as falas dos agentes e o resultado. É evidência, não verdade: a decisão é sempre do dono.

## Em cada pasta
- `briefing.md`: o que os agentes receberam.
- `rodadaN-instrucoes.md`: o que cada rodada pediu.
- `r1/`, `r2/`, `r3/`: a fala de cada agente (o ID está em `agentes.md`).
- `conversa.md` (só no 6): a transcrição completa, em ordem.
- `medicoes/` (só no 6): o código das medições de performance e de integração.
