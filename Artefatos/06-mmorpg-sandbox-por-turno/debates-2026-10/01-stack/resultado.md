# Resultado do debate de stack (3 rodadas, 6 agentes)

- Núcleo e servidor: TypeScript (5 de 6 na posição final; Go como alternativa).
- Servidor: próprio, Node + WebSocket + Postgres (5 de 6; SpacetimeDB com módulo TS só como dissidência, spike na fase 3).
- Cliente: Unity (3 posições finais + 2 votos como alternativa); Godot (1 + 4 votos); Three.js (2).
- Cliente não roda regra: estado + prévia + eventos em JSON. Núcleo só com inteiros.
- Regras: stack só se rediscute com a fase em curso jogável; cada rediscussão troca uma camada só, nunca o núcleo; cliente só troca se reprovar no teste do personagem modular, com destino já decidido.
