# Sobre esta cópia — eras-do-brasil-semi-idle

Cópia dos arquivos da branch `main` do repositório
`github.com/sidinei-silva/eras-do-brasil-semi-idle`, trazida em 21/10/2026 para que o
repositório pudesse ser apagado. Os arquivos ao lado deste são exatamente os do repo; este
arquivo é o único acrescentado.

- **O que era:** o recomeço de outubro em TypeScript — monorepo com `packages/core`
  (regras de combate determinísticas), servidor Node, playground/depurador web e dados em
  `data/`. Combate por turno instanciado em filas (*lanes*) e casas, com modo ativo e
  caçada automática. Nasceu como `eras-do-brasil` e foi renomeado quando o projeto
  recomeçou de novo em 21/10.
- **Período:** 05/10 → 14/10/2026, 17 commits. Parte do código do core e do playground foi
  escrita por agente de IA — o que levou à declaração de 14/10 de que o jogo estava
  "totalmente indeciso".
- No clone local havia uma única alteração não commitada: o `CLAUDE.md` (1 linha) apagado.
  A cópia segue o GitHub, então ele está aqui.
